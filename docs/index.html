Page Change Agent

A marketing team files a website change as a GitHub issue. A Claude agent reads the page from the CMS, drafts the edit as an unpublished draft, checks it against the site's compliance rules, and replies with a before and after diff. Anything risky goes to compliance instead. A person still clicks publish.

    Where 90 tickets went

    The 30 requests ran 3 times each against a real Contentful space. Every saved draft was unpublished and read back exactly: 66 drafts saved, 66 read back exactly as sent, 0 published.

    • Draft, low risk 30
    • Draft, customer-facing 36
    • Sent to compliance by the agent 24

    The agent routed every risky request itself, so the compliance checks never had to stop a draft. Median agent time 2.6 s per ticket, $0.0129 per ticket with claude-opus-5-5.

    How it works

    1File

    An issue form. Page, part of the page, what should change, and new copy if there is any. Only people with write access trigger the agent.

    2Draft

    Claude reads the page from the CMS and either proposes field edits with a risk tier or sends the request to compliance with a reason. Structured output, so the reply always has the same shape.

    3Check

    Rules the model cannot talk past. Disclosures stay, no banned claims (guarantees, lowest price, no risk), rates are not edited, links go to real pages, meta descriptions fit, alt text is real.

    4Save

    An unpublished draft through the Contentful Management API, with the page's version number so two edits cannot overwrite each other, then read back and compared. The issue gets the diff and a label.

    Limits

    • The website is invented: ten pages for a made-up insurer, with disclosure rules written for this demo. A real deployment starts from the customer's own content model and compliance rules.
    • Contentful stands in for the CMS. Enterprise sites often run Adobe Experience Manager, which needs its own connector.
    • The risk tiers are a starting point. Which edits may skip a full read should be agreed with the customer's compliance team and checked on real tickets first.
    • A judge model grades whether each draft does what was asked; rules grade everything else.
